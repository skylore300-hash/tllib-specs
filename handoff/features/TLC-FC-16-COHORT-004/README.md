# TLC-FC-16-COHORT-004 — Typological distance descriptor

This is a structural-only handoff for the typological distance formula in `maths/16-cohort/cohort.md`. The source names a geodesic, a type-space metric `g`, a classification map `Phi`, an inverse/preimage term, pure type representatives, and a coefficient `lambda`, but does not construct the geometry needed to evaluate the expression. The implementation therefore preserves the complete source formula and its type references as an opaque descriptor and rejects local semantic distance evaluation.

No geodesic solver, classification map, type center, metric, interpolation, or numerical integration rule may be invented. A future external scientific geometry provider is required before a numeric typological distance can be produced.
