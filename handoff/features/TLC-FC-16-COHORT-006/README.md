# TLC-FC-16-COHORT-006 — Cohort algebraic and graph descriptor

This package represents the source Cohort quintuple `C=(D,R,circle,sim,G)`. It validates that the weighted graph vertex set is exactly the Disciple set, preserves the learning relation, collaboration-operation reference, equivalence partition, and graph, and records the source statement that the collaboration operation forms a magma that is generally not associative. The implementation may validate structure but must not infer associativity or additional algebraic, relational, graph, or causal properties.

The package is structural: it gives a developer an autonomous representation and validation task without importing semantics from Master, Disciple, Community, or other domains beyond the scientific references explicitly declared by Cohort.
