# TLC-FC-16-COHORT-013 — Collective intelligence and synergy metrics

This package evaluates the source collective-intelligence expression and then the synergy value obtained by subtracting the supplied proportion-weighted individual-intelligence term. The six type proportions, `omega_i` weights, `alpha`, `beta`, `gamma`, cohesion, diversity, expected typological distance, and individual-intelligence values are scientific inputs. The source does not calibrate or infer them.

A conforming implementation therefore performs only the stated aggregation on complete compatible supplied data. It must reject missing terms or shape mismatches and must never invent type weights, expected distance, individual intelligence, or coefficient values to make the formulas executable.
