# TLC-FC-18-EVALUATION-002 — Technical progression metrics

This package specifies the source expressions for `m_t1`, `m_t2`, and `m_t3`. Norms, derivatives, second derivatives, temporal integration, `sigma`, dot products and contextual references are explicit providers rather than locally invented mathematics. Invalid denominators are structured errors, and no quadrature, finite-difference rule, hidden clamp or replacement sigmoid is permitted. The handoff therefore preserves literal scientific evaluability while keeping all unspecified numerical realization outside this feature.
