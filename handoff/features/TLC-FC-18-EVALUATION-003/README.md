# TLC-FC-18-EVALUATION-003 — Contextual progression metrics

This package specifies `m_c1`, `m_c2`, and `m_c3` without creating the scientific ingredients the source leaves open. The expectation over contexts, the distribution semantics behind it, `C_optimal(E)`, `w(E)`, norms and `sigma` are external providers. The implementation must preserve the source expectation, prudence/analysis cosine, weighted resolution-to-complexity ratio and innovation term. Monte Carlo synthesis, invented weights, invented optimal contexts and denominator clamps are explicitly forbidden.
