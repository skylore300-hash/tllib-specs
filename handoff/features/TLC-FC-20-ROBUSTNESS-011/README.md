# TLC-FC-20-ROBUSTNESS-011 — Traditional principle distance expression

This finalized package evaluates `D_trad(P)=||P-P_trad||^2 + nu C_coh(P)` only from provider-supplied norm/difference, traditional reference, coherence and coefficient values. It does not construct `P_trad`, a norm, a metric space, a coherence function, a projection, or any estimator. The arithmetic and positive-square term are preserved exactly as sourced.
