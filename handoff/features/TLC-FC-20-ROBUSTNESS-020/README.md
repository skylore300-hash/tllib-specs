# TLC-FC-20-ROBUSTNESS-020 — Structured knowledge complexity expression

This finalized package preserves `G_T=(V,E,W,T)` and the source complexity sum/inequality using provider-supplied node costs, edge costs, traditional graph distance, coefficient and `C_max`. It does not construct a graph, infer topology, define complexity, learn weights, build traditional distance, or solve the inequality. Evaluation is conditional on complete supplied quantities.
