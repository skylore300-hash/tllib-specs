# TLC-FC-20-ROBUSTNESS-028 — Normalized contextual robustness expression

This finalized package evaluates the source contextual product from provider-supplied minimum, `P(c)`, `P_max`, fidelity, `F_fid^max`, alignment and `Alig_max`. All three maxima are required non-zero. No reference maxima, context search, extrema calculation, normalization data, probability estimator, fidelity estimator, alignment estimator, epsilon repair, or clamping is introduced.
