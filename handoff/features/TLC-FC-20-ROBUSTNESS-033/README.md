# TLC-FC-20-ROBUSTNESS-033 — Robustness health index expression

This finalized package evaluates the raw source `Q_rob^T` product/exponential expression from provider-supplied systemic robustness, alignment efficiency, adaptability, fidelity, covariance terms and tradition-gradient norm. It does not estimate covariance, gradients, or upstream indices, and it does not apply the separate `0.75` predicate internally. The raw index remains distinct from health classification.
