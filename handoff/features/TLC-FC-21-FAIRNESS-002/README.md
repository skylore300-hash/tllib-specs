# TLC-FC-21-FAIRNESS-002 — Bias space descriptor

Expose the source-defined five-dimensional bias-space structure as a descriptor: statistical, algorithmic, cultural, cognitive, and traditional bias components form a Cartesian product contained in `R^5`. This handoff does not define, score, estimate, merge, or otherwise operationalize any of the five component spaces. Implementations must preserve their distinct names and structural role.
