# TLC-FC-21-FAIRNESS-003 — Aggregate bias expression

Evaluate the aggregate bias equation from five supplied bias values, supplied weights, supplied pairwise correlation values, and a supplied traditional-distance value. The package performs only the source arithmetic. It must not construct any bias component, infer weights, estimate correlations, or implement a traditional-distance metric. Missing scientific operands are explicit provider failures rather than invitations to synthesize data.
