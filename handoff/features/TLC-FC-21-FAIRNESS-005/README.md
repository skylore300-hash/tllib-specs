# TLC-FC-21-FAIRNESS-005 — Fair optimization problem descriptor

Expose the minimization objective and its five source constraints as a structural mathematical problem, not as an algorithm. Bias limits remain upper bounds, performance and fidelity remain lower bounds, and all thresholds remain uncalibrated. This package must never introduce gradient descent, SQP, KKT solving, dual ascent, parameter search, or fabricated epsilon values. Future solver work requires separate scientific authority.
