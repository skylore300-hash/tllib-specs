# TLC-FC-21-FAIRNESS-015 — Bias-decay inequality descriptor

Expose the source asymptotic inequality `beta_T(t) <= beta_0 exp(-lambda t) + beta_infinity^T` as a theorem/inequality descriptor. The residual term is described as bias attributable to legitimate differences, but the source does not operationalize legitimacy, estimate `beta_infinity^T`, or prove universal exponential decay. This package therefore performs no legitimacy classification, residual-bias estimation, convergence proof, or certification.
