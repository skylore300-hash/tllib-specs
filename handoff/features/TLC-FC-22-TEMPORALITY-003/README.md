# TLC-FC-22-TEMPORALITY-003 — Temporal distance certification guard

This finalized structural guard protects the boundary between the source matrix `g_tau` and a genuine temporal metric distance. The source provides no sufficient positive-definiteness conditions and no executable distance or geodesic construction. Therefore this feature exposes only an availability assessment and requires external scientific evidence for both requirements before any downstream implementation may claim a true metric distance.

It never invents a coefficient domain, norm, geodesic, path integral or numerical distance procedure. Missing science remains visible through structured errors and traceable unresolved items.
