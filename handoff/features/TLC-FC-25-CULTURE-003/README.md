# TLC-FC-25-CULTURE-003 — Cultural participation in contextual weighting descriptor

## Purpose

Record that culture participates in Context weights `w_i(X,t)` and couplings `gamma_ij(X,t)`, and that cultural weight variation remains part of the general Context dynamics.

## Execution

`structural_only`. `g_c` and the weight equation remain owned by Context 24. This package never creates `g_culture` or an autonomous cultural ODE.

## Drivers

Events, crises, innovations, and social transformations are preserved as qualitative drivers because the Culture source gives no quantitative mapping from those events to weights.
