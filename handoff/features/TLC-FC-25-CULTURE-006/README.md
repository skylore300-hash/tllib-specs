# TLC-FC-25-CULTURE-006 — Cultural adaptation delegation to Context

## Purpose

Represent legitimate cultural adaptation exactly as a case of `A_contexte`, not as a new cultural operator.

## Execution

`conditionally_executable`. The caller must provide a provider conforming to `TLC-FC-24-CONTEXT-007`, scientific evidence identifying sensitive forms eligible for adaptation, and evidence identifying robust elements that must be preserved.

## Boundary

No `A_culture`, optimizer, differentiator, or unsourced eligible-set rule is allowed. Culture delegates to Context and records the robust-preservation obligation.
