# TLC-FC-26-IDENTITY-006 — Identity attractor family descriptor

This finalized structural package preserves the three attractor families explicitly announced by the Identity source: integrated identity, divided identity, and identity oscillations. The integrated family retains the qualitative `X ≈ R` characterization, while the source's convergence, contagion, and polarization language remains descriptive rather than a numeric classifier.

No threshold, basin, attractor-solving procedure, or proof of existence is supplied by the source, so this package exposes descriptors only and rejects requests that would require fabricated quantitative attractor semantics.
