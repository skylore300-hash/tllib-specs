# TLC-FC-26-IDENTITY-007 — Isolated convergence theorem claim guard

This finalized structural guard preserves the isolated-subject convergence theorem exactly as a theorem claim: its stated assumptions, fixed-point conclusion, and exponential-convergence wording are traceable, but the chapter does not supply a complete general Lyapunov proof, basin characterization, or executable convergence-rate construction.

Consequently the package does not claim to certify convergence from arbitrary runtime data. Such certification requires an external proof/evidence provider; otherwise it returns a structured unsupported-science error rather than manufacturing a proof or rate.
