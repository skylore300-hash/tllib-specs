# TLC-FC-26-IDENTITY-012 — Identity recovery-time indicator guard

The Identity chapter names “return time below `Phi_seuil`” as an additional indicator but does not provide a standalone computational definition, sampling rule, interpolation rule, or crossing convention in domain 26. This finalized structural guard preserves that indicator as a traceable scientific concept while preventing an invented numeric algorithm.

Reflexivity 27 contains related material, but it is a later domain and remains read-only here. Its formulas are not imported as Identity authority. Numeric recovery time is allowed only when an explicit external definition/provider is supplied downstream.
