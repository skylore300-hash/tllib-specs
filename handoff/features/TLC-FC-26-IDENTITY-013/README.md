# TLC-FC-26-IDENTITY-013 — Contextual robustness orientation guard

The Identity source names a “contextual robustness” indicator using a minimum relative-gap orientation and explicitly notes that this orientation can seem inverse to the name. The complete computational definition is not sufficiently fixed in domain 26. This finalized structural guard therefore preserves the exact minimum-oriented semantics and the warning together.

An implementation must not replace the minimum with a maximum, reverse the direction to make the label sound more intuitive, or invent a missing numeric formula. Unsupported semantic execution remains a structured scientific-boundary error.
