# TLC-FC-27-REFLEXIVITY-004 — Dissonance and crisis-threshold assessment

This package compares an Identity-provided `Phi_id` value with the Identity-provided opaque `Phi_seuil`. It may report the source predicate `Phi_id > Phi_seuil` as an above-threshold crisis trigger condition, but it does not invent threshold calibration, crisis duration, termination, or a realignment state machine.
