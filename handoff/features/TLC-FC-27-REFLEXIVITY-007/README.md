# TLC-FC-27-REFLEXIVITY-007 — Recovery-time conditional evaluator

This package validates externally supplied recovery evidence against the source threshold-crossing semantics `inf{tau: Phi_id(t+tau)<Phi_seuil | Phi_id(t)>Phi_seuil}`. It does not solve the infimum, integrate a trajectory, search for a root, invent a return-time bound, or claim finite recovery without evidence.
