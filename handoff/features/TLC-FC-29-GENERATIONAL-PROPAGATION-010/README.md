# Empty invariant-core guard

Finalized Feature Handoff Package v1.0 for domain 29 Generational Propagation. This executable guard protects the finite-core Q_rep denominator. A finite invariant-core cardinality of zero must produce the declared EmptyInvariantCore structured error. The implementation must not return zero, infinity, NaN, or another numeric fallback for the empty core. This guard preserves the source limitation around finite cardinality and introduces no runtime dependency or invented scientific repair.
