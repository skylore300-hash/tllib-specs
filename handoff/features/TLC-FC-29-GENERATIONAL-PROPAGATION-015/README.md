# Erosion-time consistency ambiguity guard

Finalized Feature Handoff Package v1.0 for domain 29 Generational Propagation. The source makes d depend on Q_rep(t) while using d as a generation-constant in the erosion approximation. This structural guard preserves that inconsistency explicitly. It forbids rewriting d as d(t), integrating d over time, or replacing the source expression with a generation product. No scientific repair is invented.
