# Critical reproduction-threshold evaluator

Finalized Feature Handoff Package v1.0 for domain 29 Generational Propagation. This conditionally executable feature evaluates R_c=1+(sigma_R^2/E[R])*f(rho,kappa) only from supplied final statistics and supplied f. E[R] must be nonzero. The package does not construct expectation or variance estimators, invent f(rho,kappa), repair a zero expectation, or introduce a branching-process model.
