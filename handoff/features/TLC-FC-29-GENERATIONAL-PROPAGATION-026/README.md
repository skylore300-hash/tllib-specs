# Generational diversification predicate

Finalized Feature Handoff Package v1.0 for domain 29 Generational Propagation. This conditionally executable feature evaluates max_i d_D(x_i,N_inv) < delta_rupture from supplied branch distances and threshold. The comparator remains strictly less-than. d_D, N_inv and delta_rupture are not constructed or calibrated by this package, and no weakened boundary or additional scientific dependency is introduced.
