# TLC-FC-32-DRIFT-AND-CORRECTION-007 — Writing-pressure calibration guard

The chapter assumes commensurability after weighting for the writing-pressure expression but provides neither units nor calibration rules. This finalized structural guard preserves that limitation and rejects hidden normalization, standardization, coefficient fitting, or unit conversion.

No executable calibration engine is published by this package. The feature records the unresolved boundary needed by feature 006 while keeping the source function `sigma` opaque and supplied.
