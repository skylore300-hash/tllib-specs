# TLC-FC-32-DRIFT-AND-CORRECTION-010 — Mission intensity index

This finalized handoff preserves the exact product of the vitality, engaged-fraction, and joy ratios. Each maximum appearing in a denominator is supplied and guarded against zero before evaluation.

The package does not construct the joy index, estimate maxima, normalize observations, or infer missing survey semantics. It evaluates only the source-defined ratio product when required values are available, with missing scientific quantities remaining provider-backed.
