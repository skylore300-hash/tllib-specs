# TLC-FC-32-DRIFT-AND-CORRECTION-011 — Rupture predicate

This finalized handoff preserves the rupture set as a predicate with exactly four simultaneous source conditions: doctrinal distance, critical support count, value degradation, and sufficient environmental support. The logical connective is `AND` across all four conditions and is never rewritten as `OR`.

`N_inv`, `d_D`, branch states, values, support measures, and thresholds remain provider-backed where the chapter does not construct them. Fidelity 35 is not used as a runtime provider.
