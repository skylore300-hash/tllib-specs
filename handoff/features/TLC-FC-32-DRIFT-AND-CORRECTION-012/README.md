# TLC-FC-32-DRIFT-AND-CORRECTION-012 — Schism-path ambiguity descriptor

The source conceptually distinguishes doctrinal, institutional, cultural, and personal schisms but supplies no separate equations for those paths and does not resolve their relation to the four-way conjunctive rupture predicate.

This finalized structural descriptor preserves that ambiguity. It does not invent four classifiers, four mathematical equations, an `OR` rule, or an algorithmic taxonomy. The package records the unresolved scientific distinction without extending the chapter.
