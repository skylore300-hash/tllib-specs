## Module boundary

The final module distinguishes:

- representing a capacity object from validating it;
- referencing an object from inferring a relation endpoint;
- associating source context from scoring context;
- representing activation from applying activation;
- representing manifestation from observing manifestation;
- representing metric symbols from measuring;
- representing comparison tokens from comparing capacities;
- representing development equations from simulating development.

Only the first structural behavior in each distinction is available where supported by the source contracts.

## Decisions and blockers

There are no blockers preventing the required structural implementation specification.

Nine features propagate `scientific decision required`: `002`, `003`, `006`, `007`, `009`, `011`, `012`, `014` and `015`. These decisions are classified `deferred_to_scientific_review`; they prohibit scientific execution but do not prevent construction, validation, storage and structural queries.

All other undefined scientific values are preserved as opaque values, external references, external observer/comparator/evaluator requirements or implementation-out-of-scope behavior.
